# multiagentSystem 核心計劃與決策台帳

更新：2026-10-17。這是每個專案可採用的公開計劃範本，也是本專案的工作台帳。GitHub Issues 是需求與驗收的權威來源；PR、review、CI 與實機紀錄是交付證據。勾選 TODO 前必須逐項核對最新證據。不得把執行階段 agent 身分、帳號、額度、私人 prompt、記憶、憑證寫入此文件或 GitHub。

欄位規則：每個 TODO 有穩定 ID、優先序（M1/M2/M3）、負責角色、依賴、Issue/PR 證據、下一決策。未列出有效的最新 head、review、CI、實機證據時均視為「待驗證」。每次變更都要更新日期及證據，不能以 CI 全綠直接表示功能完成。狀態衝突先保持未完成，PM 核對 GitHub 後再改。M1 是 MVP；M2 是受控協作；M3 是發佈驗收。

Core Plan 中點擊 TODO 可定位原文；展開 TODO 可開啟本專案的 Issue／PR 報告。連結使用 `依賴：Issue #12；證據：PR #7；`（也接受 `dependency:`／`evidence:`）。依賴欄位的裸 `#12` 視為 Issue，證據欄位須明寫 Issue／PR；同類清單可寫 `PR #7／#8`。其他倉庫的 `owner/repo#12` 或 URL 不會轉成本專案連結。未指定連結顯示「待連結」；報告連結與 TODO 勾選均不代表 GitHub 狀態已核實。
