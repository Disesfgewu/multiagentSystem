# Discuss with PM Agent（Issue #308，第二部分）

在編輯器選取一段程式碼（專案檔案，或 PR 報告開出的 patch），按右鍵 **Discuss with PM Agent**（或命令面板，需有選取），輸入問題，確認後把「檔案、行號範圍、選取的程式碼、問題」組成一行 prompt 打進 **PM 角色** agent 的終端機。

- 不接受任何參數；選取內容、問題、確認都來自這個視窗。未信任的工作區不能用。
- 路徑是相對於專案資料夾的路徑（不送絕對路徑）；patch 檢視的數字是 patch 文字的列號，prompt 會說明。
- 程式碼視為**資料**：包在 `«…»`、最多 1200 字元（超過會寫明少送多少）、換行以 `⏎` 表示、縮排壓縮；含隱藏／方向字元、或本套件自己的標記字樣 → 拒絕；含憑證、本機路徑、email（發佈前同一個掃描器）→ 整個不送，錯誤訊息只講類別、不重複內容。
- 送達規則與 #305／廣播相同（共用 `confirmAndType`）：只送給 CLI 自己說正在等輸入的 PM；狀態不明要按第二個明確按鈕；確認後會再讀一次選取的文字，變了就不送；結果記在派發紀錄（kind: discussion，不存文字）。
- 「已打進終端機」不等於 PM 讀了或會回覆。沒有用真的 CLI 驗證（#135）。

**還沒做**：Start Meeting（多 agent 同題、彙整回覆成會議紀錄）。
