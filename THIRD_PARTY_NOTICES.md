# Third party notices

The extension uses the following packages at runtime: fflate to read the fixed GitHub CLI ZIP archive and
the fixed Codex CLI gzip archive, and smol-toml to check a Codex `config.toml` before and after the folder trust entry is added. The CLI assets (gh, Codex, Claude Code) are downloaded to extension-private user storage;
they are not bundled in the VSIX. Their source, version, digest, and licenses are recorded in
`docs/TOOL_SOURCE_MATRIX.md`.
